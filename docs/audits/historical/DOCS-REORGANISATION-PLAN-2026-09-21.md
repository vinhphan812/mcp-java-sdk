appears to be the accepted successor to ADR-000X (which is still Draft). The correct action is to assign the next
sequential number:

- Option A: Rename `ADR-000X` → `ADR-0017-sse-permit-response-flow.md` (preserves draft status, adds proper number)
- Option B: Merge content of ADR-000X into ADR-0016, delete ADR-000X
  **Recommended:** Option A — rename to ADR-0017, update ADR README index.
